# Bio Link - Ravyou

Website Bio Link personal yang responsif, modern, dan clean untuk menampilkan link sosial media dan dukungan.

## File Proyek
* `index.html` - File utama website (struktur, gaya, dan interaktivitas).
* `foto profil.jpeg` - Foto profil yang digunakan di halaman.

## Cara Menjalankan Secara Lokal
Cukup buka file `index.html` di browser Anda untuk melihat tampilannya secara lokal.

## Penyebaran (Deployment)
Halaman ini dideploy secara gratis menggunakan **GitHub Pages**.
